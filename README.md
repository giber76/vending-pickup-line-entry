# One Line, One Minute: The Vending Machine Pickup Line Contest

Entry for [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee)
on make.fun — one pickup line, 200 characters at most, as if a vending
machine were flirting with a passing human.

## The line (161 characters)

> Press B4 — I've held your favorite at eye level all day. Exact change only... and if you come back tomorrow, I'll jam the coil on purpose, just to keep you here.

## Why this line

- **Spoken by the machine itself:** "Press B4", "I've held", "I'll jam
  the coil" — not a line any stranger in a bar could say.
- **The machine's own world:** the B4 button, the snack held at eye
  level, exact change, the coil that drops the goods.
- **The punch lands last:** the machine admits it will fake a jam on
  purpose, just to keep the human standing there.
- **Short and speakable:** 161 characters, one breath, nothing tacked on
  that dilutes the joke.
- **Charming, not creepy:** a machine playing hard to get with its own
  coil — warm enough to make a passer-by smile.

## How it runs

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt`. Run locally with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
